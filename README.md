# web2026_elias_brabaender

Anwendung starten:
Im Terminal "./gradlew clean bootRun" ausführen. Die Seite kann dann unter  http://localhost:8080/admin erreicht werden.
Unter dem Ordner Frontend muss "npm run dev" im Terminal ausgeeführt werden. Diese Seite ist dann unter  http://localhost:5173 erreichbar.
Ersteres kann mit den Zugangsdaten Name:admin Passwort:admin zugegriffen werden (wäre in einer Realanwendung natürlich undenkbar). Dort kann man dann Nutzer erstellen, mit dessen Daten man sich dann im Frontend einloggen kann.
